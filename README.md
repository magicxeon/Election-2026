# 📊 แดชบอร์ดวิเคราะห์ผลการเลือกตั้ง 2026 (ฉบับเจาะลึก)

เครื่องมือวิเคราะห์เชิงสถิติสำหรับการเลือกตั้งปี 2569 เปรียบเทียบที่มาคะแนนและการเปลี่ยนแปลงผู้สมัครรายบุคคลจากปี 2566

## 🚀 ฟีเจอร์หลัก
- **แผนภาพการกระจายคะแนน:** วิเคราะห์การไหลของคะแนนจาก 77 จังหวัดสู่พรรคการเมืองในรูปแบบ Sankey Diagram
- **วิเคราะห์ผู้สมัครย้ายพรรค (Switcher Analysis):** ติดตามผู้สมัครที่ย้ายสังกัด พร้อมเปรียบเทียบส่วนต่างคะแนนที่ทำได้
- **วิเคราะห์ฐานเสียงจังหวัด:** แสดง 5 อันดับจังหวัดที่พรรคนั้นๆ ได้รับความนิยมสูงสุด
- **ตัวกรองหมายเลขผู้สมัคร:** กรองดูเฉพาะผลกระทบของหมายเลข 1-9 (เลขตัวเดียว)

## 🛠 วิธีการใช้งาน (Local Development)
เนื่องจากโปรเจกต์นี้ใช้ `fetch()` ในการโหลดข้อมูล JSON เพื่อความปลอดภัยของ Browser คุณจำเป็นต้องรันผ่าน **Local Server** เท่านั้น:

1. เปิดโฟลเดอร์โปรเจกต์ด้วย **VS Code**
2. ติดตั้ง Extension ชื่อ **"Live Server"**
3. คลิกขวาที่ไฟล์ `election_ultimate_v8.html` แล้วเลือก **"Open with Live Server"**
4. หากต้องการอัปเดตข้อมูล ให้รันสคริปต์ Python ในโฟลเดอร์ `exporter/` (จำเป็นต้องมีไฟล์ Excel ต้นฉบับ)

## 📁 โครงสร้างไฟล์ที่สำคัญ
- `election_ultimate_v8.html`: ไฟล์หน้าจอหลัก
- `js/`: โค้ดควบคุมตรรกะและการวาดแผนภูมิ
- `data/`: ข้อมูลผลคะแนนในรูปแบบ JSON
